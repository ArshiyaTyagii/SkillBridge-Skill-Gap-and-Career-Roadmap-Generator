# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue.

Instead, contact the repository owner privately through the contact method listed on their GitHub profile. Include:

- A description of the vulnerability.
- Steps to reproduce it.
- The potential impact.
- Any suggested mitigation.

Do not include real credentials, private resumes, or personal information in a report.

## Security practices

- Keep secrets in local environment variables.
- Never commit `.env` files or credentials.
- Validate uploaded files and user-provided input.
- Restrict file types and file sizes for resume uploads.
- Avoid logging resume contents or other sensitive personal data.
- Keep dependencies updated.

This policy applies to the current and future components of SkillBridge.
